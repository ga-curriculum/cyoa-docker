## Foreword
Welcome to Docker! This lesson and pre-recording are meant to get you up to speed on working with Docker, an increasingly popular virtualization software.

## Lesson Plan
By the end of this lesson, students should be able to:
* Describe what Docker is, the basics of how it works, and recognize its use-cases in practice
* Download, run, and clean up Docker images and containers
* Run TensorFlow/Keras code on a GPU using Docker
